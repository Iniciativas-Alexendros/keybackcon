# Índice de documentos

Puerta de entrada a `docs/`: cada documento en una línea (qué contiene y para quién).

- [`ARCHITECTURE.md`](ARCHITECTURE.md) — cómo está organizado el código (CLI, GUI y flujos); para quien quiera modificarlo.
- [`DECISIONS.md`](DECISIONS.md) — decisiones de diseño (ADR) con su motivo; para quien quiera entender los porqués.
- [`PROTOCOL.md`](PROTOCOL.md) — especificación técnica del protocolo HID LampArray; para depuración de bajo nivel.
- [`DEVELOPMENT.md`](DEVELOPMENT.md) — checklist de calidad, empaquetado y release; para quien contribuya o publique.
- [`ROADMAP.md`](ROADMAP.md) — qué está hecho y qué falta; para quien quiera saber a dónde va el proyecto.
